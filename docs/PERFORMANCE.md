# 性能与验收记录

## 预算与实现

| 项目 | 目标 / 上限 | 实现 |
|---|---:|---|
| 渲染 FPS（60 秒中位数） | ≥ 50 | 120 帧滑窗中位数，实时显示 |
| 推理 FPS | ≥ 20 | 单飞推理，最短间隔 45 ms |
| 推理输入 | 最长边 640 px | 720p 显示保持不变；仅识别帧降至 640×360，输入像素减少 75% |
| Worker 回传 | 只传实际消费字段 | 478 点缩至 36 个 Face Oval 点，blendshape 缩至 5 项 |
| 特效触发延迟 P95 | ≤ 150 ms | 视频帧采样到特效渲染的滚动 P95 |
| 雨滴 | ≤ 180 | 固定对象池预算 |
| 烟花 | HIGH 120 / MEDIUM 90 / LOW 60 | 物理粒子与质量档直接绑定 |
| 减少动态效果 | 烟花 ≤ 36 | 30 FPS、无额外光晕/遮挡批次 |
| 粒子 draw call | HIGH/MEDIUM ≤ 3；LOW ≤ 2 | 雨、后景烟花、前景烟花实例化批次 |
| AR 礼物三角面 | ≤ 1800 | 星轨光环和低模深度遮挡体共用一个 Three.js 场景与 WebGLRenderer |
| AR 礼物生命周期 | 1000 ms | 非 React 帧级更新；雨 6%/秒、烟花 18%/次，命中后 3 秒冷却 |
| 首页 GLB | 传输 < 1 MB | 2.49 MB 源文件 → 624 KB Meshopt/WebP 运行文件 |
| 表情引导资产 | 单张 < 80 KB | 384×384 透明 WebP：微笑 12.14 KB、大笑 11.77 KB |

连续低 FPS 会触发 `HIGH → MEDIUM → LOW` 降级：雨/烟花预算分别为 `180/120`、`135/90`、`90/60`，渲染分辨率倍率分别为 `1`、`0.9`、`0.78`。稳定恢复后逐级升档，避免频繁抖动。

## 已完成的自动化验证

- 表情状态机：阈值持续时间、微笑雨、大笑优先、烟花冷却、回中性复位。
- 物理：16 边碰撞体、镜像绕序归一、高速粒子连续碰撞、头部速度冲量与 60 FPS 碰撞体插值。
- 粒子：五火箭时间轴、容量上限、雨滴清除、前后景深度层、径向角度分层、爆点级双色调、碰撞闪光保持时间。
- AR 礼物：初始无佩戴、非天气状态永不掉落、雨中概率与帧率无关、烟花事件概率、1000ms 到期、3 秒冷却、头部中心/宽高/滚转、真实 Z 厚度、不可见深度遮挡体、总三角面预算、减少动态效果冻结星轨、LOW 档减少行星细节。
- 音效：点击开始只恢复空的 Web Audio 上下文，不创建真实素材的 BufferSource；首次烟花惊讶声只播放一次，雨声循环、烟花声单次播放，600ms 淡出。
- 质量控制：低帧降级与恢复升档。
- 坐标：镜像与 `object-fit: cover` 映射。
- 产物：中文 SSR 首页、摄像头入口、Worker、MediaPipe、Three.js 实例粒子与无障碍降级声明。
- 回放：固定表情序列可重复得到微笑、一次大笑烟花和回中性；60 秒粒子 CPU 负载回放验证 HIGH/LOW 预算不越界。
- 顺序引导：每次开启直播重置；微笑完成后才允许推进到大笑提示，大笑完成后隐藏中央文案；完成后图标只随实时雨/烟花状态出现。
- 宽屏布局：浏览器实测桌面舞台 957 × 538.3125 CSS px，比例 1.7778；左栏 DOM 已移除，右栏保持完整。
- 表情图标稳定性：微笑与大笑共用 48×48 固定槽和 310px 状态胶囊，浏览器逐状态测得 `x/y/width/height` 差值均为 0。

## 目标机现场验收方法

环境：Windows 11、Chrome 当前稳定版、i5-1135G7 / Iris Xe 或同级、720p 摄像头。

1. 打开部署链接并加 `?debug=1`，允许摄像头，完成校准。
2. 连续运行 60 秒：中性 10 秒、微笑 20 秒、大笑并左右摆头 20 秒、离开与回到画面 10 秒。
3. 记录 HUD 中 Render、Vision、Effect latency、Particles、Quality、Delegate。
4. 使用录屏回看：大笑时雨应立即停止；烟花不得明显穿过头部；快速摆头应改变粒子方向和速度；星轨光环出现时，后半部应被真人头部遮住，1 秒后必须自动消失。
5. 同时覆盖权限拒绝、摄像头占用、低光、眼镜、快速转头和人脸离开后恢复。

本地视觉回归可先使用 `?debug=1&replay=1` 跳过摄像头，验证五枚火箭、画面变暗、遮挡层、粒子预算和音效状态；该模式额外提供“测试3D礼物”按钮检查星轨光环，但正式页面不存在手动佩戴入口。回放不能替代人脸识别准确率与真人视频遮挡验收。

说明：自动化环境没有真实摄像头和指定硬件，不能诚实替代该 60 秒现场性能认证；仓库交付的是可观测的实时计量、确定性核心测试和完整验收步骤，而非伪造的目标机数据。
# 3D 穿戴资产预算

- 墨镜源文件 5.1 MB / 120,000 三角面；发布资产使用 Meshopt、10,006 三角面，约 100 KB。
- 帽子源文件 7.3 MB / 120,000 三角面 / 2048px 纹理；发布资产 11,684 三角面、512px WebP，约 197 KB。
- 以完整静态产物而不是单文件判断 ROI：Meshopt 让共享加载器 chunk 增加约 27 KB，但两件模型合计减少约 444 KB，净减少约 417 KB 下载量。
- 两份 GLB 不在开播时预载；只在对应摇头事件发生后按需加载，网络文件由浏览器 HTTP 缓存复用。
- 穿戴配饰与粒子共用现有 WebGLRenderer 和 requestAnimationFrame，且同时最多显示一件。
- 墨镜/帽子改为摇头后按需加载到固定侧边层，仅显示 2 秒；到期后执行场景移除以及几何、材质、纹理释放，GPU 不保留隐藏模型。
